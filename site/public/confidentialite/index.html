Confidentialité

Sur ce site

Aucun cookie, aucun traceur, aucune statistique de visite, aucune publicité, aucun script d'un tiers (la seule requête vers un tiers est celle décrite ci-dessous). Votre choix de thème reste dans votre navigateur ; il n'est envoyé nulle part.

La section de téléchargement interroge api.github.com pour connaître la dernière version publiée (sans cookie, sans identifiant), et lit ensuite automatiquement le fichier SHA256SUMS sur github.com, quand votre navigateur l'autorise. Ces requêtes partent de votre navigateur vers GitHub, qui les traite selon sa propre politique ; nous n'en recevons rien. Les fichiers eux-mêmes se téléchargent depuis GitHub.

Cloudflare, qui sert le site, tient aussi ses propres journaux techniques. Nous n'avons pas vérifié ce qu'ils contiennent ni combien de temps ils sont gardés.

Dans le programme Smart Route

Smart Route tourne sur votre ordinateur. Vos demandes, vos résultats, votre historique et vos réglages restent sur votre ordinateur : Yolea ne les reçoit pas, et il n'existe pas de compte Yolea.

Le programme lance les outils installés chez vous (Claude Code, Codex, Antigravity), avec vos connexions. Ce que vous envoyez à un outil est traité par son éditeur, selon vos conditions avec lui.

La version web est servie par le programme lui-même, à l'adresse 127.0.0.1 de votre ordinateur : elle n'est pas joignable depuis un autre appareil.

Ce que nous ne faisons jamais

Nous ne vendons jamais vos données personnelles et nous n'affichons pas de publicité.

Qui y a accès

Pour ce site : Cloudflare, qui sert les pages, et GitHub, qui publie les fichiers. Pour le programme : personne chez Yolea, puisque rien ne nous est envoyé.

Vos droits

Vous pouvez nous écrire à contact@yolea.ai pour toute question sur vos données. Les données de Smart Route sont sur votre ordinateur : vous les supprimez en supprimant le dossier de données du programme.
