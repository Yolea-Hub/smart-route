Arrêtez de comparer les IA. Découvrez tout ce qu'elles savent faire pour vous.

Smart Route lit ce que vous voulez faire, choisit parmi les assistants IA auxquels vous êtes déjà abonné, les fait travailler ensemble, vous montre son plan, et ne lance rien sans votre accord.

Télécharger

Pour Linux, Windows et macOS. Sur vos propres comptes, sur votre ordinateur.

Voir comment ça marche

Le problème

Trois abonnements, trois fenêtres.

Vous payez pour Claude, pour ChatGPT, pour Gemini. Chacun est bon à autre chose, et chacun vit dans sa propre fenêtre.

  • Une question passe d'un outil à l'autre par copier-coller, et le contexte se perd en route.
  • Personne ne vous dit quel modèle convient à quelle tâche : vous devinez, ou vous prenez toujours le même.
  • Le quota du mois part sur un modèle trop puissant pour une question simple, et il manque le jour où la tâche est difficile.
  • Quand un outil relit son propre travail, il est d'accord avec lui-même.

Pourquoi nous l'avons créé

Nous l'avons d'abord écrit pour nous.

Chez Yolea, à Abidjan, nous travaillons chaque jour avec ces trois outils. Notre fondateur, Thierry Memel, faisait lui-même le tri : celui-ci pour écrire du code, celui-là pour chercher, un troisième pour relire. Le geste revenait sans cesse.

Nous avons écrit le programme qui fait ce tri à sa place, et qui demande avant d'agir. Il tourne chez vous, avec vos comptes. Nous le publions parce que le même problème se pose à toute personne qui paie plusieurs abonnements IA.

Comment ça marche

Trois chemins, une seule route.

Vous décrivez la tâche. Smart Route choisit l'outil de chaque étape, les chemins se rejoignent, et vous recevez une réponse unique, relue.

Claude
Écrire, programmer
Codex
Relire le code
Gemini
Chercher, lire long
Smart Route choisit
Votre réponseune seule, relue
Chaque outil s'allume pendant qu'il travaille.

  1. Vous décrivez

    Une question, une recherche, une modification de code. En français ou en anglais.

  2. Smart Route propose

    Il classe la tâche, puis montre son plan : quel outil, quel modèle, quel niveau d'effort, en mots et non en chiffres.

  3. Vous validez

    Rien ne démarre avant votre accord. Vous pouvez changer un outil ou arrêter.

  4. Il exécute et relit

    Les outils tournent sur votre ordinateur. Pour le code, un second outil, d'un autre éditeur, relit le travail du premier.

Vos comptes, votre ordinateur

Rien ne passe par Yolea.

Smart Route est un programme installé chez vous. Il lance les outils de votre ordinateur, avec vos connexions.

Télécharger

Un fichier par système.

Le téléchargement est gratuit. Chaque fichier est publié avec son empreinte SHA-256, pour que vous puissiez vérifier qu'il n'a pas changé en route.

Bientôt disponible. Les fichiers ne sont pas encore publiés.

Télécharger

Linux

Bientôt disponible

    Installer sur Linux
    1. AppImage : rendez le fichier exécutable, puis lancez-le.
    chmod +x Smart-Route-*.AppImage && ./Smart-Route-*.AppImage
    1. Paquet .deb (Debian, Ubuntu) :
    sudo apt install ./smart-route_*.deb

    Si l'AppImage ne s'ouvre pas sur Ubuntu 22.04 ou plus récent, installez libfuse2 (paquet libfuse2t64 sur Ubuntu 24.04).

    Windows

    Bientôt disponible

      Installer sur Windows
      1. Ouvrez le fichier .exe téléchargé.
      2. Windows affiche « Windows a protégé votre ordinateur », parce que le programme n'est pas encore signé. Choisissez Informations complémentaires, puis Exécuter quand même.
      3. Suivez l'installeur, puis ouvrez Smart Route depuis le menu Démarrer.

      macOS

      Bientôt disponible

        Quelle puce ? Menu Pomme, puis À propos de ce Mac. « Puce Apple M… » : Apple Silicon. « Processeur Intel… » : Intel.

        Installer sur macOS
        1. Ouvrez le fichier .dmg et glissez Smart Route dans Applications.
        2. Au premier lancement, macOS refuse d'ouvrir le programme, qui n'est pas encore signé. Fermez le message.
        3. Sous macOS 15 ou plus récent : Réglages Système, Confidentialité et sécurité, descendez jusqu'à Smart Route, puis Ouvrir quand même.
        4. Sous macOS 14 ou plus ancien : clic droit sur Smart Route, puis Ouvrir.

        Pour vérifier un fichier : sous Linux, sha256sum fichier ; sous macOS, shasum -a 256 fichier ; sous Windows, Get-FileHash fichier dans PowerShell. Le résultat doit être identique à l'empreinte affichée ci-dessus.

        Version web

        Dans votre navigateur, depuis votre ordinateur.

        Smart Route peut aussi s'ouvrir dans un navigateur. Cette version est servie par le programme lui-même, sur votre ordinateur : il n'existe pas de version hébergée chez nous.

        1. Dans Smart Route, ouvrez les réglages et activez « Accès depuis le navigateur ». Le programme affiche un code de 8 caractères, valable 5 minutes.
        2. Dans votre navigateur, ouvrez cette adresse : http://127.0.0.1:47821
        3. Saisissez le code.

        L'adresse ne répond que sur votre ordinateur, et seulement tant que le programme est ouvert. Si le port 47821 est pris, Smart Route utilise 47822, 47823 ou 47824 : l'adresse exacte est affichée dans ses réglages. Depuis le navigateur, les tâches sont en lecture seule : elles ne modifient aucun fichier.

        Questions

        Ce que l'on nous demande.

        Est-ce gratuit ?

        Le téléchargement et l'usage de Smart Route sont gratuits. Smart Route n'ajoute aucun abonnement : il utilise ceux que vous avez déjà, et le prix de chacun reste fixé par son éditeur.

        Quels comptes faut-il ?

        Au moins un de ces outils, connecté sur votre ordinateur : Claude Code (compte Claude), Codex (compte ChatGPT), Antigravity (compte Google). Smart Route compose avec ceux qui sont connectés, et vous dit ceux qui manquent.

        Mes données partent-elles chez Yolea ?

        Non. Vos demandes, vos résultats et votre historique restent sur votre ordinateur. Seuls les outils que vous avez choisis les reçoivent, chacun selon ses propres conditions.

        Quels systèmes sont pris en charge ?

        Linux (AppImage et paquet .deb), Windows (installeur .exe, 64 bits) et macOS (Apple Silicon et Intel).

        Pourquoi le programme n'est-il pas signé ?

        Signer un programme pour Windows et pour macOS demande un certificat payant, renouvelé chaque année, que nous n'avons pas encore. Sans lui, Windows et macOS affichent un avertissement à la première ouverture : les étapes pour l'ouvrir sont décrites plus haut. Les empreintes SHA-256 publiées vous permettent de vérifier le fichier.
